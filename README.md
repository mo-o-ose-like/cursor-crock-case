# Cursor — Groq в существующем чате

Внешний вид, название «Помощник Cursor», вкладки и стили исходного MVP сохранены.

## Запуск

В корне проекта нужен `.env` (не публикуйте его):

```dotenv
AI_BASE_URL=https://api.groq.com/openai/v1
AI_MODEL=openai/gpt-oss-120b
AI_API_KEY=ваш_ключ_Groq
PORT=8080
```

Запуск: `python3 server.py`. Если сервер уже работает, остановите Ctrl+C и запустите заново, затем обновите страницу Cmd+Shift+R.
Откройте http://127.0.0.1:8080 → сделка → What if → кнопка помощника.

## Что подключено

Новые сообщения существующей формы отправляются в `/api/chat`. Сервер добавляет актуальные данные сделки, сценарий и недавнюю переписку, затем обращается к Groq. Ответ и ссылки на источники показаны прежними карточками; источники открываются прежним диалогом. В окне источника отображаются русские названия полей и понятные значения вместо JSON. Старые сохранённые JSON-источники тоже преобразуются при открытии. Внутренние ID участников исключены из нового контекста модели.

Вкладки «Риски», «Гипотезы», «Советы» продолжают работать по исходным правилам. Старые сообщения сохранены. Новые сообщения ИИ не исполняют команды изменения карты. Состояние ожидания, ошибки API и лимиты показаны внутри существующей карточки ответа; при ошибке отправьте вопрос снова. Без ключа сервер сообщает, что модель не подключена, а не имитирует ответ ИИ.

Сервер отбирает до 30 источников и сокращает контекст по консервативной оценке размера запроса под бесплатный тариф. История ограничивается последними 19 сообщениями и может дополнительно сокращаться. При частичном охвате источников об этом сообщается в ответе. Реальное число токенов зависит от модели; при частых запросах возможен HTTP 429. Автоматических повторов с расходом квоты нет.

Ключ читается сервером только при запуске, в браузер не передаётся. `.env`, `.git` и Python-файлы не раздаются через HTTP. История и сделки остаются в localStorage браузера; общей базы и настоящей авторизации пока нет. Сервер слушает только 127.0.0.1.

## Проверки

`npm test` — тесты сервера, истории, бюджета контекста, ссылок и неизменности карты от вопросов ИИ.

Для браузерной проверки нужен установленный `@playwright/test` и браузер Chromium. При запущенном сервере: `npm run test:browser`. Для установленного Chrome: `BROWSER_CHANNEL=chrome npm run test:browser`. Тест использует подставные ответы, не расходуя квоту Groq, и проверяет исходный заголовок, вкладки, форму, источники, историю, ошибки, отмену/повтор и отсутствие изменений карты. Отдельно проверяются неполные источники, сетевые сбои и прерванные запросы. HTTP-тесты поднимают сервер на временном локальном порту, внешние API не вызывают.

Каталог datasets содержит отдельно подготовленные вымышленные данные. Новые кнопки импорта в интерфейс не добавлены.

Документация: https://console.groq.com/docs/openai и https://console.groq.com/docs/structured-outputs.
