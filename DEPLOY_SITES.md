# Размещение чата на существующем Sites

Сайт: https://cursor-krok-deals.basicbracelet16.chatgpt.site

Готова адаптация для серверного ESM Worker. В продакшене Python не нужен: один Worker раздаёт прежние файлы сайта и обрабатывает `/api/chat`. Supabase не требуется. Данные и история по-прежнему хранятся отдельно в браузерах.

## Вике — порядок действий

1. Принять изменения PR и обновить исходники существующего Site. Не создавать новый Site. Сохранить идентификатор из `.openai/hosting.json`.
2. В серверных переменных Sites сохранить `AI_API_KEY` со своим ключом Groq. По желанию задать `AI_MODEL=openai/gpt-oss-120b` и `AI_BASE_URL=https://api.groq.com/openai/v1`; эти значения уже используются по умолчанию. Локальный `.env` на хостинг не копируется.
3. Настроить доступ участников команды в Sites. По умолчанию `/api/chat` требует вход через платформу: проверяется предоставляемый Sites заголовок `oai-authenticated-user-id`. Демонстрационная кнопка входа внутри приложения не заменяет этот вход.
4. Выполнить сборку `npm run build:sites` и опубликовать существующий Site через Sites из той же версии исходников. Сборка не публикует сайт сама.
5. Открыть прежнюю ссылку под аккаунтом участника команды и проверить вопрос, уточнение и источники. Если ключ меняется — требуется повторный деплой для применения переменных окружения.

Ключ не вставляется в JavaScript браузера, `.openai/hosting.json`, GitHub или сообщения PR. Общая ссылка использует один серверный ключ; участникам свои аккаунты Groq не нужны.

## Формат сборки

Нужен Node.js 20+. Никаких npm-зависимостей для сборки устанавливать не требуется.

```bash
npm run build:sites
```

Результат:

```text
dist/
  .openai/hosting.json
  server/index.js
```

`dist/server/index.js` — самостоятельный ES-модуль с `default.fetch`. Публичные HTML/CSS/JS, шрифты, изображения и учебный JSON встроены в него сборщиком. `.env`, Python-файлы, тесты, Git и инструкции не публикуются. Макет и содержание исходных публичных файлов не меняются.

Источник конфигурации теперь `.openai/hosting.json` без поля `static`; прежний корневой `hosting.json` удалён, чтобы не было двух разных режимов публикации. ID существующего Site сохранён. Для Sites source helper оставшаяся команда сборки: `["npm", "run", "build:sites"]`, после которой упаковывается полученный `dist` из того же коммита. Публикует владелец/редактор Site по стандартному процессу Sites.

## Локальная проверка

Прежний `python3 server.py` продолжает работать с локальным `.env`.
Общий системный промпт и названия полей находятся в `chat-policy.json`, его используют обе реализации.

```bash
npm test
npm run build:sites
npm run preview:sites
```

Превью точного Worker-артефакта: http://127.0.0.1:8082. Оно слушает только loopback и отключает платформенную проверку входа исключительно для локальной проверки. `.env` автоматически не загружает. Для реального локального запроса к Groq можно запустить `node --env-file=.env scripts/preview-sites.mjs` (при этом порт берётся из `.env`, например 8080). Ключ остаётся в Node-процессе, не в артефакте.

`npm test` проверяет обе реализации, требует Python 3.10+ и Node.js. Браузерная проверка существующего интерфейса: `SERVER_URL=http://127.0.0.1:8082 BROWSER_CHANNEL=chrome npm run test:browser`, при установленном `@playwright/test` и Chrome. Тест подставляет ответы и не расходует Groq.

## Границы текущего MVP

Проверка входа рассчитана на доверенные заголовки, которые добавляет платформа Sites. Не следует размещать этот Worker вне Sites с тем же предположением о заголовках. `AI_REQUIRE_AUTH=false` явно отключает проверку; для общего ключа на публичном сайте это открывает расход квоты анонимным посетителям, поэтому штатная настройка — проверку сохранить.

Ограничение одновременных запросов действует в пределах одного Worker isolate, а не как глобальная квота. Квоты самого Groq всё равно действуют; при их достижении чат возвращает понятную ошибку без автоматических повторов. Для большого публичного сервиса потребуются устойчивые ограничения расходов и общая база, но для командного MVP они не являются условием подключения Groq.
